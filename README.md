# LibramLZ

A lightweight mod for PolyTrack that allows LZ: track code shortening. Features both importing an exporting and significantly optimizes track codes. For PolyModLoader/PML 35.7.5

---

To use:
Boot: open an instance of PML (latest version) import the mod as the Github URL through the Mods tab.
Import: Click the Import button and paste in your LZ: text.
Export: Copy a track code in standard format, click Export, paste it in, and copy your LZ: text.
